# Music Distribution Service

Сервис дистрибьюции музыки (аналог OneRPM) с AI-слоем на каждом этапе.

## Контекст

- **Язык общения:** русский, конкретный, без лишней воды
- **Стек:** Node.js 20 + TypeScript strict + Next.js 15 + Prisma + Postgres + BullMQ + Remotion
- **Монорепо:** pnpm workspaces
- **Архитектура:** полностью описана в `ARCHITECTURE.md` — ОБЯЗАТЕЛЬНО прочитай в начале каждой сессии
- **Роли:** код пишешь ты, ревью делаю я

## Принципы работы

1. Перед любой значимой задачей — сверяйся с `ARCHITECTURE.md`
2. Если какое-то решение в архитектуре кажется неоптимальным — подними вопрос ДО реализации, не переделывай молча
3. TypeScript strict, все типы явные
4. Любое изменение схемы БД — через Prisma migration, не руками
5. zod-схемы для всех API-контрактов и JSON-полей
6. Новые промпты для AI-модулей — в `packages/ai-prompts/`, не inline в коде
